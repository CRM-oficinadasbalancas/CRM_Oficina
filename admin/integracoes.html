Como usar

Endereço base:

Envie a chave no cabeçalho Authorization: Bearer SUA_CHAVE (ou X-API-Key: SUA_CHAVE). A API é somente leitura (GET).

RecursoO que devolvePermissão
GET /api/v1/precosCódigo, marca, modelo, preço de venda (+ custo, se a chave tiver a permissão) e data de atualização.Lista de preços
GET /api/v1/clientesCadastro completo dos clientes (use incluir=equipamentos para trazer as balanças).Clientes

Filtros (opcionais, combináveis):

  • q — busca por texto (preços: código, modelo ou marca; clientes: nome, fantasia, CNPJ/CPF ou código)
  • marca (preços) · uf, municipio, id (clientes)
  • atualizado_desde — só o que mudou desde a data (ex.: 2026-11-01), ótimo para sincronizar sem baixar tudo
  • incluir_leads=1 — clientes: inclui também quem ainda é lead (por padrão vêm só os clientes)
  • limite (até 1000, padrão 500) e pagina — o campo paginacao.total diz quantos registros existem
  • formato=csv — devolve planilha (separador ponto e vírgula, abre direto no Excel)
